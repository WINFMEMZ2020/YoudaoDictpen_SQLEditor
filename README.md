# YoudaoDictpen_SQLEditor
适用于有道词典笔3代的SQL编辑脚本，用于播放视频

# 使用方法
在下载本仓库或release后，打开launcher.py或launcher.exe，按照提示操作即可。<br>

# v1.5更新内容
